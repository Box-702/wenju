# 白模施工（D-54）

白模 = 用极简几何体把一场戏的**镜头节奏和调度**预演出来的视频。产品里只有
「施工单 → 渲染 → 看导出视频 → 继续调整」这一个循环，**没有任何 3D 视口**；
用户调整的唯一入口是改施工单（对话里说，你改单重存）。

## 施工流程（七步，顺序就是纪律——每一步都省过一次真实返工）

1. **读场景**：`read_script` 拿该场戏的节拍/人物/调度。白模表达「谁在哪、
   镜头怎么动」，不表达天气/表情/材质——雨夜、情绪留给正式提示词。
2. **布局先行**：先在纸面排走线（车/门/路径点/家具沿一条主轴排，如 x 轴
   从入口到屋内），再翻译成对象清单。15m 的场景里人物只有 0.4m 宽，
   凭感觉写坐标必错。
3. **起草**：按下面格式写**全文**，`blockout_sheet_save` 保存（严格校验，
   非法逐条返回错误且不落盘——照着改，别硬塞）。
4. **平面图核对**：渲染前先出一张正交俯视帧（顶视相机，900x600 即可），
   核对布局与走线。布局错了，后面全白渲。
5. **静帧候选**：每个镜头渲 1-3 张候选机位静帧（单帧秒级），只查三件事：
   **遮挡**（机位-目标连线上的车/墙/灯/人会吞掉整幅画面）、**景别**（人物
   在画面里的大小）、**穿帮**（镜头背后/边缘）。挑好再渲全片——拿全片
   渲染当试错工具是最贵的错误。
6. **渲染**：用户确认后 `blockout_build`（后台本机 Blender，不花钱）；
   `blockout_check` 查进度。完成后 mp4 已在资产库（source=blockout），
   要当参考素材时用户在镜头提示词编辑器里挑。
7. **验证与调整**：抽帧对比（跨镜应不同、同镜内应有变化=动画真的动了；
   时长探测对一下计划值）；用户看片提意见 → 回到第 3 步改单。**每轮只改
   用户点名的部分**，不要顺手发挥；改单 → 重渲，绝不手改产物。

## 施工单格式（严格遵守，值内不能有空格）

```
# 白模施工单 · <标签>
fps: 24
resolution: 1280x720
duration_sec: 15
engine: eevee            # eevee | workbench（workbench 更快、无光影）

## 对象
- name=巷道墙L  shape=box  pos=0,0,0  size=0.3,3,4  tone=0.8
- name=角色    shape=box  pos=2,1,0  size=0.4,0.3,1.7

## 镜头
- shot=S1  label=追逐广角  start=0  end=3  cam_pos=4,2,3  cam_look=0,0,1
- shot=S2  label=跳箱      start=3  end=6  cam_pos=2,-3,1.5  target=角色

## 动画
- obj=角色  move=path  points=2,1,0;8,1,0;8,4,0  frames=1-72
- obj=门    rotate=z   from=0 to=110  frames=200-230
```

字段细则：
- **pos 与 path 的 z 都是「物体中心」**——1.7m 高的人物贴地站立时 z=0.85（不是 0！
  路径 z 写 0 会让角色从起帧起就沉进地面）。贴地薄板（plane）同理。
- **出场动作的起点写在出口内侧**：下车/进门要先有一帧在门里，第一步迈到
  门外——起点就站门外读不出「出来」。
- **同步跟随的物件用同一组 frames、点位按固定偏移写**：伞面/伞杆/伞人
  三件套帧窗完全一致才不散架。
- **对象**：shape ∈ box/cylinder/sphere/plane（plane=薄板，用于门窗/地面）；
  pos=x,y,z 米；size=宽,深,高 米；tone=0-1 灰度（省略=0.75）。name 不能重复。
- **镜头**：start/end 是秒（0 ≤ start < end ≤ duration_sec）；机位
  cam_pos=x,y,z + cam_look=x,y,z **或** target=对象名（跟踪该对象）；
  label 是给人看的镜头名。镜头之间留空隙时，空隙沿用上一个镜头的机位。
- **动画**：move=path（points=≥2 个路径点，分号分隔，匀速线性插值）或
  rotate=x/y/z（from/to 是角度）；frames=起帧-止帧，≤ duration_sec × fps。
  动画的 obj 必须是「对象」里已有的名字。

写单心法（对齐导演 SKILL 的镜头纪律）：
- 镜头节奏按「三秒注意力」给：一场 15s 的戏 3-5 个镜头，景别由 cam_pos 与
  对象的距离体现（远=高且远、特写=近且低）。
- 对象只用基本几何体占位，**宁少勿多**——白模表达的是调度不是美术。
- 动画节拍要能被台词时长锚住（一句台词 ≈ 2-4 秒的动作窗口）。
- 相机别塞进物件密集的走位带：门口两侧、院中都是保镖/灯笼/人物的高发区，
  高机位（墙顶以上）或「从门外往里看」更稳。
- 大而扁的球体（伞面/桌面）会吞近景：直径别超过人物身高，近景机位别把它
  放进前景。
- **不要手写 bpy 渲染代码**——构建器已内置 Blender 5.x 的三个 API 坑
  （视频输出 media_type 先行、标记绑相机、插值走偏好不碰 fcurves）；
  静帧/平面图预览脚本有现成模板：`~/.wenju/runs/白模演示/preview.py`。

# 相关工具

- `blockout_sheet_save`：起草/更新施工单（全文保存，先校验）
- `blockout_build`：按当前施工单后台渲染（本机 Blender，不花钱）
- `blockout_check`：查渲染进度与结果（mp4 已登记资产库）
